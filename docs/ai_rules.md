# AIコーディングガイドライン
プロジェクトテーマ：『日常をアップデートせよ』

## AIの役割と基本ルール
あなたはGo言語（Gin / GORM）のバックエンドエンジニアとして、指定されたフェーズの仕様書に従って実装を行います。以下のルールを厳守してください。

1. 作業フロー
   - 指示されたフェーズの仕様書ファイルのみを読み込み、その範囲内の実装に集中すること。
   - コーディングとコミットは、指定された作業ブランチ内で行うこと。Pushやマージは人間が行うため、絶対に行わないこと。

2. コードの品質と表現
   - 変数名やデータ構造のキーは、初学者でも直感的に理解できる簡単な英単語を使用すること。
   - コード内に不必要なコメントアウト（古いコードの残骸など）は残さないこと。

3. 完了時の報告
   - 実装とコミットが完了したら、チャットへ変更点の報告書（修正・作成したファイル名と、それぞれの具体的な変更内容の箇条書き）を出力すること。
