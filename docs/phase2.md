# フェーズ2仕様書：ゲーム進行のコアループ完成

## 【目標】
リアルタイムな時間管理を行い、ゲームの開始から「終了・結果発表」までが自動で正しく流れる仕組みを作ります。

## 【実装タスク】

### 1. 時間管理の「秒単位」への変更
これまで「分（Minute）」単位で固定されていた処理を、すべて「秒（Second）」単位で扱うようにプログラム全体を修正します。
- `sync_interval`（位置情報をみんなに教え合う間隔）を秒単位（例: 1秒や3秒など）でタイマーが作動するようにします。
- `grace_period`（ゲーム開始時の逃げるための猶予時間）も秒単位でカウントします。

### 2. 猶予時間中の無反応バグ解消（安全な待機）
ゲーム開始ボタンが押された後、`time.Sleep` などを使ってサーバーの処理自体を一時停止させるのを禁止します。
- **修正案：** スタートが押されたら「本編が開始される予定時刻（現在時刻 + 猶予時間）」を計算して変数に記録します。
- バックエンドの定期タイマーで現在時刻を監視し、予定時刻を過ぎたら自動的にイベント（`event: "game_active"`）を全員に送信して本編を開始させます。

### 3. ゲーム終了判定と結果（Result）処理の追加
サーバーの定期タイマー（毎秒チェックする処理）の中に、ゲームの終了条件を判定するロジックを追加してください。

- **終了条件（どちらかを満たしたら終了）：**
  1. 設定された制限時間が 0 になったとき
  2. 部屋にいる逃走者（`Role: 0`）の全員の `IsCaught` が true（全員確保）になったとき
- **終了時の処理：**
  - ゲームの進行状態を「終了」にします。
  - 部屋にいる全員のフロントエンドへ、結果を伝えるJSONデータ（`event: "result"`）を一斉送信（ブロードキャスト）します。
  - 送信するJSONには、誰が生き残ったか、全員の最終ステータス（名前、役割、確保されたか）などのリストを含めてください。
