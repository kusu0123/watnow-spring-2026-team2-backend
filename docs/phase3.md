# フェーズ3仕様書：フロント連携の強化（仕上げ）

## 【目標】
デザイン班（Figma）の画面仕様と完全に連動させ、マップの視認性を高めるとともに、エラーが起きた際もアプリが落ちない親切な設計にします。

## 【実装タスク】

### 1. メンバーカラーの実装
マップ上で誰がどこにいるかを見やすくするため、プレイヤーごとのカラー情報を扱えるようにします。
- **入室時：**
  - `action: "join"` の際に、フロントエンドから送られてくるJSONに `color`（例: "#FF0000" や "blue" などの文字列）を追加し、受け取れるようにします。
  - 受け取ったカラー情報を、フェーズ1で用意したDBの `Color` カカラムとメモリ（Hub等）に保持します。
- **同期時：**
  - 定期的に全員の位置情報を一斉送信している `event: "sync"` のJSONレスポンスの中に、各プレイヤーの `color` も含めて送信するように書き換えてください。

### 2. エラー通知機能の実装
想定外のデータが送られてきた場合や、不正な操作（存在しないユーザーを捕まえようとする等）があった際、サーバー側でエラーを握りつぶさず、フロントエンドに理由を教えてあげる仕組みを作ります。
- エラーが発生した場合は、原因となったクライアント（送信元）に対してのみ、以下のような分かりやすいエラー用JSONを返却する共通処理（関数など）を実装してください。
- レスポンスの形（例）：
  `{"event": "error", "message": "エラーが発生した理由を簡単な言葉で記述"}`
